# `02_governance/metodo/` — fuente del método

`/metodo` será la página del método en el sitio (8.18): un capítulo por módulo, en el orden de `SIM.do`, generado desde el repo.

**Regla:** ninguna frase del método nace fuera del repo. Si no está en un header de módulo, un memo o esta carpeta, no se publica.

Desde 8.15, todo header de módulo lleva la sección 9, «Específico de México»; de ahí sale el capítulo 0.

- `plantilla-capitulo.md`: formato de cada capítulo (encabezado, secciones 1–10, esquema de `metodo.json`).
- `cap0-requerimientos.md`: qué hace falta para replicar el simulador en otro país.

Primer capítulo escrito con la plantilla: `Households`, en `../CUAD-0.md`.
